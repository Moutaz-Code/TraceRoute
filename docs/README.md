# Documentation

This folder holds project-level documentation for the Android app.

## Suggested structure

- `architecture/` — high-level system design, module boundaries, and runtime flow
- `decisions/` — architectural decision records (ADRs) and other long-lived choices

## Current project notes

The codebase is still very small, so keep documentation lightweight and focused on:

- app structure
- rendering / game loop flow
- input handling
- data storage and loading
- future feature decisions
