# Demo Manual Checklist

Use this checklist for the current due-date demo build.

## World Route

- Start in Living Room with clean art, no debug labels.
- Tap `Handheld`; handheld opens and closes cleanly.
- Navigate route:
  - Living Room -> Entry
  - Entry -> Kitchen
  - Kitchen -> Office
  - Office -> Living Room
- Confirm the missing CCTV room is not part of the normal route.

## Laptop

- Open panels:

  - Activity

  - Draft
- Confirm each panel marks as read and adds/keeps evidence.
- Close laptop.

## Handheld / Endgame

- Open handheld.
- Check Evidence, Threads, Timeline, Statements.
- Confirm final timeline unlocks after all required evidence.
- Enter the final sequence in true order.
- Confirm `Confront Partner` appears.
- Complete confrontation and verify case completion dialog.
- Test `Return to Apartment`.
- Test `Reset Run` only after recording/demoing completion.
